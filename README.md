# Homebrew Tap for Qstats

Official Homebrew Tap for [Qstats](https://github.com/qg-hs/Qstats).

## 安装 / Installation

```bash
brew install --cask qg-hs/tap/qstats
```

或者添加 Tap 后安装：

```bash
brew tap qg-hs/tap
brew install --cask qstats
```

## 更新 / Upgrade

```bash
brew upgrade --cask qstats
```

## 卸载 / Uninstall

```bash
brew uninstall --cask qstats
```
